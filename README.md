# 🚀 AI 应用开发实战库 (LLM / RAG / Agent)

本项目库包含两个核心的 AI 业务落地项目：**企业级 RAG 知识库问答系统** 与 **合同风控审核 Agent**。
项目均采用现代软件工程架构，涵盖 API 封装、数据库持久化、Prompt 调优及 Docker 容器化部署。

## 📦 项目一：企业级 RAG 知识库问答系统

### 📖 项目简介
基于大模型（LLM）与 RAG（检索增强生成）架构的私有知识库问答系统。重点解决了大模型在真实业务场景下的**“知识幻觉”**与**“多轮对话指代不明”**等工程痛点。

### ✨ 核心特性
- **🔄 Query Rewrite (问题重写)**：针对多轮对话中的指代词（如“它”），系统会自动结合上下文重写为完整 Query，大幅提升检索召回率。
- **💾 会话记忆持久化**：接入 MySQL 数据库，实现聊天记录的实时落盘，支持基于历史记录的多轮对话。
- **🛡️ 模块化工程架构**：遵循单一职责原则（SRP），将数据库层、RAG 引擎层与 API 路由层彻底解耦，具备极高可维护性。

### 🛠️ 技术栈
`Python` `FastAPI` `LangChain` `ChromaDB` `MySQL` `Docker` `Streamlit`

## 🤖 项目二：企业级合同风控审核 Agent

### 📖 项目简介
针对传统法务审核合同耗时长、易漏风险的痛点，基于 ReAct 架构开发智能风控 Agent。实现从自动查库拉取合同、风险词检测到生成法务建议的全自动闭环。

### ✨ 核心特性
- **🧠 多工具自主编排 (Function Calling)**：定义了“合同查询”与“风险词匹配”工具，大模型可根据用户指令自主规划调用路径，实现多步推理。
- **🛡️ 高可用兜底设计**：针对工具执行超时或异常，引入 `try-except` 降级捕获，保证大模型能接管错误并自动纠错（Self-Correction），防止服务崩溃。
- **⏱️ 防死循环熔断**：在代码层设置 `Max Iterations`（最大迭代次数），防止大模型陷入无限调用工具的死循环，保障 API 成本可控。

### 🛠️ 技术栈
`Python` `DashScope (Qwen)` `Function Calling` `ReAct` `Prompt Engineering`
