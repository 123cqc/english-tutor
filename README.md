# AI 英语学习助手

## 项目简介
基于通义千问 API 的英语学习工具，输入英文句子，自动返回翻译、语法纠错和更地道的表达建议。支持多轮对话和对话历史持久化。

## 功能
- 英文句子翻译
- 语法错误指出
- 更自然的表达建议
- 多轮对话，保留上下文
- 对话历史持久化（保存到本地 JSON 文件）

## 技术栈
- Python 3
- 通义千问 API（兼容 OpenAI 接口）
- OpenAI Python SDK
- JSON（对话历史持久化）
