# Linux 系统运维笔记

## Linux 目录结构
Linux 文件系统是一个树状结构，最顶层是根目录 `/`。
- `/bin`：存放最常用的命令。
- `/etc`：存放系统配置文件和子目录。
- `/home`：普通用户的家目录。
- `/var`：存放不断变化的文件，如日志文件 `/var/log`。
- `/root`：超级管理员的主目录。
- `/usr`：存放应用程序和文件。

## 常用命令
### 文件与目录
- `ls`：列出目录内容，`-l` 显示详细信息，`-a` 显示隐藏文件。
- `cd`：切换目录。
- `pwd`：显示当前工作路径。
- `mkdir`：创建目录，`-p` 递归创建。
- `rm`：删除文件或目录，`-r` 递归删除，`-f` 强制删除（慎用）。
- `cp`：复制，`-r` 递归复制。
- `mv`：移动或重命名。

### 文本处理三剑客
1. `grep`：文本搜索工具。例如 `grep "error" log.txt`。
2. `sed`：流编辑器。常用于替换文本：`sed 's/old/new/g' file.txt`。
3. `awk`：强大的文本分析工具，常用于按列处理数据。

### 权限管理
Linux 权限分为读（r=4）、写（w=2）、执行（x=1）。
使用 `chmod` 修改权限，例如 `chmod 755 file.sh`。
使用 `chown` 修改文件所有者。

## 进程与系统状态
- `ps aux`：查看所有运行中的进程。
- `top` / `htop`：实时监控系统资源。
- `kill`：终止进程，例如 `kill -9 PID`。
- `systemctl`：管理系统服务，例如 `systemctl restart docker`。

## 网络配置与排查
- `ip addr`：查看 IP 地址和网卡信息。
- `ping`：测试网络连通性。
- `netstat` 或 `ss`：查看网络端口占用，例如 `ss -tlnp`。
- `curl`：发送 HTTP 请求，常用于测试 API 接口。

## Shell 脚本基础
Shell 脚本是包含一系列 Linux 命令的文本文件。
第一行通常为 `#!/bin/bash`，声明使用哪种解释器。
使用 `$变量名` 引用变量。
使用 `if [ 条件 ]; then ... fi` 进行条件判断。
使用 `for` 和 `while` 进行循环。
定时任务使用 `crontab -e` 编辑，格式为：`分 时 日 月 周 命令`。
