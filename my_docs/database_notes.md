# 数据库基础与进阶笔记

## 关系型数据库（RDBMS）
关系型数据库以表格的形式存储数据，使用 SQL（结构化查询语言）进行管理。
常见的关系型数据库包括：MySQL、PostgreSQL、Oracle 等。
关系型数据库严格遵循 ACID 特性：
- 原子性（Atomicity）：事务要么全部完成，要么全部不完成。
- 一致性（Consistency）：事务开始前和结束后，数据库的完整性约束没有被破坏。
- 隔离性（Isolation）：并发执行的事务之间不会互相干扰。
- 持久性（Durability）：事务完成后，数据修改是永久的。

## SQL 语句分类
1. DDL（数据定义语言）：CREATE、ALTER、DROP。
2. DML（数据操作语言）：SELECT、INSERT、UPDATE、DELETE。
3. DCL（数据控制语言）：GRANT、REVOKE。
4. TCL（事务控制语言）：COMMIT、ROLLBACK。

## 索引（Index）
索引是提高数据库查询效率的关键。它就像一本书的目录，能让数据库快速定位到数据。
常见的索引类型包括：主键索引、唯一索引、普通索引、联合索引。
虽然索引能加快查询速度，但会降低插入、更新和删除的速度，因为每次写操作都需要维护索引结构。B+ 树是 MySQL 中最常用的索引数据结构。

## 数据库范式
- 第一范式（1NF）：字段不可再分（保证原子性）。
- 第二范式（2NF）：在 1NF 基础上，非主键字段必须完全依赖于主键（消除部分依赖）。
- 第三范式（3NF）：在 2NF 基础上，非主键字段不能依赖于其他非主键字段（消除传递依赖）。

## NoSQL 数据库
NoSQL 泛指非关系型数据库，用于解决大规模数据和高并发场景。
- 键值型（Key-Value）：Redis，常用于缓存。
- 文档型（Document）：MongoDB，以 JSON 格式存储数据。
- 列族型（Column-Family）：HBase，适合海量数据。
- 图数据库（Graph）：Neo4j，适合处理社交网络等复杂关系。

## 向量数据库（Vector Database）
随着 AI 的发展，向量数据库成为热门。它专用于存储和检索高维向量。
原理是将文本、图片等非结构化数据通过 Embedding 模型转化为向量，通过计算向量之间的余弦相似度或欧氏距离，实现语义检索。
常见的向量数据库：ChromaDB、Milvus、Pinecone、FAISS。
