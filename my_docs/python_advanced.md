# Python 高级进阶笔记

## 面向对象编程（OOP）
Python 是一门支持面向对象编程的语言。面向对象的核心是将数据和操作数据的方法封装在一起。
1. 类（Class）：是创建对象的蓝图。
2. 对象（Object）：是类的实例。
3. 继承（Inheritance）：子类可以继承父类的属性和方法。
4. 多态（Polymorphism）：不同的对象可以对同一消息做出不同的响应。

### 魔术方法
Python 中以双下划线包围的方法称为魔术方法（Magic Methods）。例如 `__init__` 用于初始化对象，`__str__` 用于定义对象的字符串表示，`__len__` 用于定义 `len()` 函数的行为。

## 装饰器（Decorator）
装饰器是 Python 中非常强大的一个功能，它允许在不修改原函数代码的情况下，增加函数的功能。
装饰器本质上是一个接受函数作为参数并返回一个新函数的高阶函数。
常见的应用场景包括：日志记录、性能测试、事务处理、权限校验等。
使用 `@` 符号作为语法糖来应用装饰器。

## 生成器（Generator）
生成器是一种特殊的迭代器，它使用 `yield` 关键字来返回值。与普通函数一次性返回所有结果不同，生成器每次调用 `next()` 时才会计算并返回一个值，这使得它在处理大数据集时非常节省内存。
生成器表达式使用圆括号，例如 `(x**2 for x in range(10))`。

## 异常处理机制
在 Python 中，异常处理使用 `try...except...finally` 结构。
- `try` 块中放置可能发生异常的代码。
- `except` 块用于捕获并处理异常。
- `else` 块在 `try` 块没有发生异常时执行。
- `finally` 块无论是否发生异常都会执行，通常用于释放资源（如关闭文件）。

## 并发编程基础
Python 由于 GIL（全局解释器锁）的存在，多线程并不适合 CPU 密集型任务。
对于 I/O 密集型任务，可以使用多线程（threading）或协程（asyncio）。
对于 CPU 密集型任务，应该使用多进程（multiprocessing）。
协程（asyncio）是 Python 3.4 引入的异步编程模型，使用 `async` 和 `await` 关键字，能在单线程内实现高并发。

## 模块与包管理
模块（Module）是一个包含 Python 代码的 `.py` 文件。
包（Package）是一个包含多个模块的目录，目录下必须包含一个 `__init__.py` 文件。
使用 `import` 语句导入模块，使用 `from...import...` 导入特定的函数或类。虚拟环境（venv）是隔离项目依赖的最佳实践。
